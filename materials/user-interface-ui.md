### User Interface (UI)

* *User interface slide*  
* **User interface (UI)** \- point of interaction and communication between a human user and a digital product or machine, such as a vehicle dynamics simulation toolchain  
  * Allows end users to prepare virtual setups and execute simulations (versus script based approach)  
  * Can be installed locally or web based  
    * Local install has “offline” advantage  
  * Updated frequently  
* General workflow  
  * Components and model fits are developed and stored in a DB  
  * User arranges various inputs to represent the vehicle and experiment we want to simulate using UI  
  * User “clicks run” in UI and code behind UI passes in required inputs to vehicle model   
  * Vehicle model runs experiment  
  * Code behind UI retrieves results and sends back to the UI  
  * User retrieves results from the UI
